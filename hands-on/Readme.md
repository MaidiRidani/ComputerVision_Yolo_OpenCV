# Overview

The **Hands-on** directory contains the complete practical history of my learning journey with **Ultralytics YOLO**.

Each practical session documents a specific topic, experiment, or implementation completed throughout the learning process. Rather than only presenting the final outputs, this directory records the progression of understanding through notebooks, source code, datasets, implementation notes, and experimental results.

To keep this repository lightweight, large experiment outputs such as annotated images, processed videos, trained models, and other generated files are stored externally on **MEGA Drive**.

---

# Objectives

- Document every YOLO practical session.
- Track learning progress over time.
- Preserve notebooks and implementation code.
- Share experiment outputs through MEGA Drive.
- Build a reproducible learning history for future reference.
